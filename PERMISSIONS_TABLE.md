## Примечания

1. **Изоляция данных по ресторанам:**
   - HEAD_ADMIN видит данные всех ресторанов
   - ADMIN и REGULAR_WORKER видят только данные своего ресторана
   - Все операции автоматически фильтруются по `restaurant_id`

2. **Ограничения REGULAR_WORKER:**
   - Может работать только со своими заказами (проверка по `createdBy`)
   - Не может видеть чужие заказы в режиме редактирования
   - Не имеет доступа к административным функциям

3. **HEAD_ADMIN ограничения:**
   - Не может создавать/редактировать заказы (только просмотр)
   - Не может работать со складом (только просмотр)
   - Фокус на управлении платформой и ресторанами

4. **Гибкие права для REGULAR_WORKER:**
   - При создании работника ADMIN может выбрать любые права из списка выше
   - Если права не указаны — работник получает только базовые права (создание и редактирование своих заказов)
